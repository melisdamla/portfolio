// PROJECT 02 — CREDIT RISK SCORING MODEL & REST API

Developed an end-to-end credit risk scoring pipeline using a dataset containing 34,584 customers and 50 candidate features.

  • Implemented train-only data-quality checks, missing-value imputation and type-aware One-Hot, Ordinal and smoothed Target Encoding.
  • Combined normalized LightGBM and SHAP feature importance scores and removed highly correlated variables while retaining the more important feature.
  • Applied forward sequential feature selection with MLxtend, reducing the model from 50 candidate variables to 20 selected features.
  • Optimized LightGBM hyperparameters using Optuna and stratified cross-validation, achieving ≈0.78 ROC-AUC and 0.163 PR-AUC on an independent evaluation set.
  • Evaluated model discrimination, score concentration and explainability using ROC-AUC, PR-AUC, accumulation analysis and SHAP visualizations.
  • Persisted the trained model and preprocessing object as separate Joblib artifacts.
  • Developed a versioned Flask REST API accepting raw numerical and categorical JSON inputs, returning credit-risk predictions and probabilities.
  • Added schema validation, structured error handling, batch prediction, request tracing, health/readiness checks, optional API-key authentication and automated API tests.
LightGBMOptunaSHAPMLxtendFlask REST APIJoblib
